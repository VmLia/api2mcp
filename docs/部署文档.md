# API2MCP 部署文档

**记录项目的详细部署设计**

## 一、部署环境要求

### 1.1 硬件要求

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 2 核 | 4+ 核 |
| 内存 | 4 GB | 8+ GB |
| 磁盘 | 20 GB | 50+ GB SSD |

### 1.2 软件依赖

| 软件 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 后端运行时 |
| Node.js | 18+ | 前端构建 |
| PostgreSQL | 14+ | 主数据库 |
| Redis | 6+ | 状态管理/缓存（可选） |
| Docker | 20+ | 容器化部署 |
| Docker Compose | 2.0+ | 容器编排 |

## 三、本地开发部署

### 3.1 环境变量配置

创建 `.env` 文件（参考 `.env.example`）:

```bash
# ── 服务端口 ──
API2MCP_PORT_FRONTEND=34075
API2MCP_PORT_BACKEND=34085

# ── 前端配置 ──
VITE_API_URL=

# ── 数据库配置 ──
DB_TYPE=postgresql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=api2mcp
DB_PASSWORD=api2mcp@123
DB_NAME=api2mcp
DB_DRIVER=asyncpg
DATABASE_URL=

# ── MCP 公开访问地址 ──
MCP_PUBLIC_BASE_URL=

# ── 日志配置 ──
LOG_REQUEST_ENABLED=false
UVICORN_ACCESS_LOG=false

# ── Docker 配置 ──
API2MCP_IMAGE_NAME=api2mcp
API2MCP_IMAGE_TAG=latest
```

### 3.2 启动服务

```bash
# 启动前后端服务（自动管理端口、依赖）
./start.sh

# 停止服务
./stop.sh
```

### 3.3 访问服务

| 服务 | 地址 |
|------|------|
| 前端界面 | http://localhost:34075 |
| 后端 API | http://localhost:34085 |
| API 文档 | http://localhost:34085/apidocs |
| 健康检查 | http://localhost:34085/health |

## 四、Docker 部署

### 4.1 Docker Compose 配置

项目提供三个 Docker Compose 配置文件：

| 文件 | 说明 | 命令 |
|------|------|------|
| `docker-compose-all.yaml` | 启动所有服务（应用+数据库） | `docker compose -f docker-compose-all.yaml up -d` |
| `docker-compose-api2mcp.yaml` | 只启动应用（使用外部数据库） | `docker compose -f docker-compose-api2mcp.yaml up -d` |
| `docker-compose-middleware.yaml` | 只启动数据库中间件 | `docker compose -f docker-compose-middleware.yaml up -d` |

### 4.2 启动所有服务（推荐）

```bash
cd docker/docker-compose-api2mcp

# 启动所有服务（PostgreSQL + 应用）
docker compose -f docker-compose-all.yaml up -d

# 查看状态
docker compose -f docker-compose-all.yaml ps

# 查看日志
docker compose -f docker-compose-all.yaml logs -f
```

### 4.3 只启动应用

```bash
cd docker/docker-compose-api2mcp

# 启动应用（需要外部数据库）
docker compose -f docker-compose-api2mcp.yaml up -d

# 查看日志
docker compose -f docker-compose-api2mcp.yaml logs -f
```

### 4.4 只启动数据库

```bash
cd docker/docker-compose-api2mcp

# 启动 PostgreSQL
docker compose -f docker-compose-middleware.yaml up -d

# 查看状态
docker compose -f docker-compose-middleware.yaml ps
```

### 4.5 停止服务

```bash
cd docker/docker-compose-api2mcp

# 停止所有服务
docker compose -f docker-compose-all.yaml down

# 停止并删除数据卷
docker compose -f docker-compose-all.yaml down -v
```

## 五、环境变量配置

### 5.1 应用环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `API2MCP_HOST` | 0.0.0.0 | 后端绑定地址 |
| `API2MCP_PORT_FRONTEND` | 34075 | 前端端口 |
| `API2MCP_PORT_BACKEND` | 34085 | 后端端口 |
| `API2MCP_DB_DEL` | false | 是否重建数据库表 |
| `DB_TYPE` | postgresql | 数据库类型 |
| `DB_DRIVER` | asyncpg | 数据库驱动 |
| `DB_HOST` | localhost | 数据库主机 |
| `DB_PORT` | 5432 | 数据库端口 |
| `DB_USER` | api2mcp | 数据库用户 |
| `DB_PASSWORD` | api2mcp@123 | 数据库密码 |
| `DB_NAME` | api2mcp | 数据库名称 |
| `DATABASE_URL` | - | 完整数据库 URL（可选） |
| `REDIS_HOST` | localhost | Redis 主机 |
| `REDIS_PORT` | 6379 | Redis 端口 |
| `REDIS_PASSWORD` | api2mcp@123 | Redis 密码 |
| `REDIS_OPTIONAL` | true | Redis 是否可选 |
| `MCP_PUBLIC_BASE_URL` | - | MCP 公开地址 |
| `LOG_LEVEL` | INFO | 日志级别 |
| `LOG_REQUEST_ENABLED` | false | 请求日志开关 |
| `UVICORN_ACCESS_LOG` | false | 访问日志开关 |

### 5.2 Docker Compose 环境变量

通过 `.env` 文件或命令行覆盖：

```bash
# 通过命令行覆盖
DB_HOST=192.168.1.100 DB_PASSWORD=secret docker compose -f docker-compose-all.yaml up -d
```

## 六、多架构镜像构建

### 6.1 构建单架构镜像

```bash
# 构建镜像
docker build -f docker/docker-build/Dockerfile -t api2mcp:v1.0.0 .

# 运行容器
docker run -d -p 34075:34075 -p 34085:34085 \
  --name api2mcp \
  -e DB_HOST=your-db-host \
  -e DB_PASSWORD=your-password \
  api2mcp:v1.0.0
```

### 6.2 构建多架构镜像（amd64 + arm64）

```bash
cd docker/docker-build

# 创建构建器
docker buildx create --name mybuilder
docker buildx use mybuilder
docker buildx inspect --bootstrap

# 构建并推送多架构镜像
./build-multiarch.sh

# 或手动构建
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  -f Dockerfile \
  -t your-registry/api2mcp:v1.0.0 \
  --push \
  ..
```

### 6.3 M4 Mac 构建 x86-64 兼容镜像

M4 Mac 默认构建 ARM64 镜像，在 x86-64 Linux 上无法运行。使用多架构构建解决：

```bash
cd docker/docker-build

# 构建支持两种架构的镜像
./build-multiarch.sh
```

```
                    │  Load Balancer  │
                    │   (Nginx/CDN)   │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
         ▼                   ▼                   ▼

         │                   │                   │
         └───────────────────┴───────────────────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
              ▼                             ▼
    ┌─────────────────┐           ┌─────────────────┐
    │   PostgreSQL    │           │      Redis      │
    │   (共享存储)     │           │   (状态共享)     │
    └─────────────────┘           └─────────────────┘
```

### 7.2 Nginx 配置

```nginx
upstream api2mcp_backend {
    server 127.0.0.1:34085;
    server 127.0.0.1:34086;
    server 127.0.0.1:34087;
}

server {
    listen 80;
    server_name api2mcp.example.com;

    location / {
        proxy_pass http://api2mcp_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

```bash
docker build -f docker/docker-build/Dockerfile -t api2mcp:v1.0.1 .

docker compose -f docker-compose-all.yaml pull

```

## 九、故障排查

### 9.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 服务无法启动 | Redis 连接失败 | 检查 Redis 配置（`REDIS_OPTIONAL=true` 可跳过） |
| 数据库连接错误 | PostgreSQL 未运行或配置错误 | 检查 `DB_HOST`、`DB_PORT` |
| 前端无法加载 | dist 目录不存在 | 重新构建前端：`cd frontend && npm run build` |
| 端口被占用 | 端口已被其他进程使用 | 修改 `.env` 中的端口配置 |
| 镜像在 Linux 无法运行 | M4 Mac 构建的是 ARM64 镜像 | 使用多架构构建脚本 |
| 请求日志过多 | 未关闭访问日志 | 设置 `UVICORN_ACCESS_LOG=false` |

### 9.2 调试命令

```bash
# 查看容器日志
docker logs -f api2mcp

# 进入容器调试
docker exec -it api2mcp /bin/bash

# 检查端口占用
lsof -i :34085

# 测试数据库连接
psql -h localhost -U api2mcp -d api2mcp
```

### 9.3 日志级别

| 级别 | 说明 |
|------|------|
| `DEBUG` | 详细调试信息 |
| `INFO` | 一般信息（默认） |
| `WARNING` | 警告信息 |
| `ERROR` | 仅错误信息 |
